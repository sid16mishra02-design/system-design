# Animation assets

These GIF diagrams and still storyboards are original, deterministic drawings. Read the [walkthrough index](../../animations/README.md) for their intended meanings. To regenerate, install Pillow in your Python environment, then run `python scripts/render_animations.py`. Use `--only consistent-hash` for one diagram or `--missing` to render only missing definitions. Each output is 960 × 600 pixels. All animation states are also readable as text.
